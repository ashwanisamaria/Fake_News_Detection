# 📰 Fake News Detection using Machine Learning

A Machine Learning-based web application that detects whether a news article is **Real** or **Fake** using Natural Language Processing (NLP) techniques and a trained classification model.

---

## 📌 Project Overview

Fake news has become a major challenge in the digital world. This project uses machine learning and NLP to classify news articles as either **Real** or **Fake** based on their textual content.

The model is trained on a labeled dataset and deployed using a simple web interface built with **Streamlit**.

---

## 🚀 Features

- 🧠 Machine Learning-based text classification
- 📝 Input any news article text
- ⚡ Instant prediction: Real News or Fake News
- 🌐 User-friendly Streamlit web interface
- 💾 Pre-trained model and vectorizer saved using Joblib

---
